

## Plan: Select All + Bulk Fulfill from Stock + PDF Summary

### What
1. **Select All Filtered Rows** — Add a checkbox in the table header that selects/deselects all currently visible (filtered) rows
2. **Bulk Fulfill from Stock** — A button that processes all selected in-stock items, automatically allocating inventory quantities to their respective POs and calling the fulfill-from-stock edge function for each
3. **Fulfillment PDF Summary** — After bulk fulfillment completes, generate a downloadable PDF report with a clean layout showing all fulfilled items, quantities, PO details, and timestamps

### Architecture

```text
Filter rows → Select All checkbox (header) → "Bulk Fulfill from Stock" button
  → Iterates selected rows with inventory match
  → For each: calls handleFulfillFromStock (existing edge function)
  → Collects results into fulfillment history array
  → Opens PDF Summary dialog with export
```

### Changes

**File: `src/components/POTracker.tsx`**

1. **Select All Checkbox** — Replace the static `CheckSquare` icon in the table header (line ~6040-6045) with an actual `Checkbox` component that:
   - Checks if all visible `ordersToDisplay` are selected
   - On toggle: selects or deselects all rows (handling consolidated sub-orders)
   - Shows indeterminate state when partially selected

2. **New state**: `bulkFulfillOpen` (boolean), `bulkFulfillResults` (array of fulfilled items for PDF)

3. **"Bulk Fulfill from Stock" button** — Added to the snapshot lock indicator bar (or as a standalone action bar when rows are selected). Only enabled when selected rows have in-stock inventory. Shows count of eligible items.

4. **Bulk fulfill handler** — `handleBulkFulfillFromStock()`:
   - Iterates each selected order that has an inventory match with `status === 'in-stock'`
   - For consolidated orders, processes each underlying PO separately
   - Calls the existing `fulfill-from-stock` edge function sequentially (to avoid race conditions on inventory)
   - Allocates `min(inventory qty, po qty)` per item
   - Collects results (success/fail per item) into state for PDF

**New File: `src/components/po-tracker/BulkFulfillSummary.tsx`**

A dialog component that renders a professional PDF-ready fulfillment report:

- **Header**: "Fulfillment Summary Report", date/time, user info
- **Summary Stats Bar**: Total Items Processed, Total Qty Fulfilled, Successful, Failed
- **Table Columns**: #, ASIN/SKU, Title, PO Number, Requested Qty, Fulfilled Qty, In-Stock Before, In-Stock After, Status (✓/✗), Serial Numbers
- **Grouped by PO**: Items grouped under PO number headers for multi-PO workflows
- **Footer**: Totals row, timestamp, "Generated by HUHA Tools"
- **Actions**: "Print" (window.print with @media print styles), "Export PDF" (html2canvas + jsPDF or window.print to PDF), "Export CSV"
- Clean professional layout: alternating row colors, clear section borders, compact but readable typography

### Data Flow

```text
User applies filters → Snapshot Lock activates
  → User clicks "Select All" checkbox in header
  → All filtered rows get selected
  → "Bulk Fulfill from Stock (X items)" button appears
  → User clicks it → Confirmation dialog shows eligible items
  → On confirm → Sequential processing:
      For each selected order with in-stock match:
        qty = min(inventory_qty, po_pending_qty)
        call fulfill-from-stock edge function
        record result
  → On complete → BulkFulfillSummary dialog opens with results
  → User can Print/Export PDF/CSV
```
